# FlowDesk — SaaS Landing Page

A responsive landing page for **FlowDesk**, an invented project-management SaaS product.
Built for the Sankar Group Front-End Development internship assignment.

## Tech
- HTML5 (semantic markup)
- CSS3 (custom properties, Grid, Flexbox, media queries)
- Vanilla JavaScript (no libraries, no build step)

## Run locally
1. Download or clone this folder.
2. Open `index.html` in any modern browser. No install or server needed.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `styles.css` | Design tokens, layout, responsive rules |
| `script.js`  | Interactions (menu, board, pricing toggle, FAQ, forms) |

## Sections
Navigation bar · Hero with interactive board visual · Logos & stats · Features (6 cards) ·
How it works · Pricing (3 plans, monthly/yearly toggle) · Testimonials · FAQ ·
Contact / demo request · Call to action · Footer

## Interactions
- Nav links smooth-scroll to sections; mobile hamburger menu
- Hero email form → validates → opens sign-up modal
- Sign-up modal and demo-request form with validation and success messages
- Clickable kanban board, count-up stats, pricing toggle, FAQ accordion, scroll reveal

No backend is used; forms show a success message only.
